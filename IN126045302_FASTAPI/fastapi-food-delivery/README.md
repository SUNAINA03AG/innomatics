# FastAPI Food Delivery App

## 📌 Project Overview
This project is a backend API built using FastAPI for a Food Delivery System.

## 🚀 Features
- GET APIs
- POST APIs with validation
- CRUD operations
- Cart and Checkout system
- Search, Sorting, Pagination
- Swagger API testing

## 📌 API Endpoints

### Food Items
- GET /items
- GET /items/{id}
- POST /items
- PUT /items/{id}
- DELETE /items/{id}

### Orders
- POST /orders
- GET /orders

## 🛠️ Tech Stack
- Python
- FastAPI
- Uvicorn

## ✅ Tasks Completed
This project includes 20 API tasks covering beginner to advanced FastAPI concepts.
