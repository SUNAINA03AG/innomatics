FastAPI Assignment 2

Description

This assignment demonstrates the implementation of FastAPI APIs.
Each question is implemented using FastAPI and the outputs are shown using Swagger UI.

Files Included

- main.py – Contains the FastAPI code for all questions.
- Q1_Output.png – Output screenshot for Question 1.
- Q2_Output.png – Output screenshot for Question 2.
- Q3_Output.png – Output screenshot for Question 3.
- Q4_Output.png – Output screenshot for Question 4.
- Q5_Output.png – Output screenshot for Question 5.

How to Run

1. Install FastAPI and Uvicorn.
2. Run the FastAPI application.
3. Open the Swagger UI in the browser.
4. Test the API endpoints.
